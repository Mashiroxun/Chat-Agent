# Live2D 桌面伙伴 1.3.8

这是 QQ Agent 的确定性插件，标识 `desktop-pet`，同时需要随本次安装提供的 Electron 窗口支持和控制台「桌宠」页面。桌宠操作由程序状态和用户交互触发；视觉模型负责画面理解与回复，不注册群聊发送工具。

在 QQ Agent 顶部打开「桌宠」：

- **角色与显示**：已有角色卡片、实际渲染缩略图与使用状态，一键切换；显示/隐藏、导入完整 `.model3.json` 模型、大小、透明度、置顶、穿透、视线追踪和位置锁定。
- **动作控制台**：真实动作与表情，独立随机动作/表情/坐站开关、活动状态、预览回执与具体失败原因、权重、间隔、点击冷却、状态映射。
- **屏幕陪伴**：复用已有模型 API 目录与密钥，自动观察开关、手动观察、停止请求、多屏选择、用量与最近回复。
- **生活与成就**：陪伴日期、有效时长、互动次数、时段与场景分布，六项成就与进度。

点击角色进行互动，回应动作开始后显示简短本地气泡，不调用 AI。单击弹出「今日用量」卡片；双击按设置打开「直接对话」或「开发工单」，默认对话，可在右键菜单或「桌宠」页的「双击桌宠打开」切换 —— 两者都不会打开控制台主窗口。「直接对话」是一条只属于主人的会话（`private:<机器人自己的QQ号>`）：你说的话以「主人」身份进这条会话的存档并跑一次完整唤醒，回复被接在窗口里、不会发到任何群；窗口不提供选群能力。对话窗支持发文件：输入框旁的「＋」选文件或把文件拖进窗口，图片走 image-cache 受控目录（看图工具可读），文本内联进正文（单文件 64KB / 总预算 128KB），其它类型明确拒发。重复点击受互动冷却限制。按住角色拖动；右键菜单中的「打开桌宠控制台」是显式设置入口。开启穿透后在「桌宠」页关闭穿透即可恢复鼠标交互。

文字气泡按内容自动调整大小，没有内部滚动条，支持文字选择与复制、关闭按钮和 Esc；悬停、选择文字或聚焦阅读时暂停自动消失。1.3.7 使用独立透明气泡窗口，回复出现、换长短和关闭都不移动或扩缩角色窗口，保留原思考动作。显示桌宠后可用「预览文字气泡」查看本地示例，不截图、不调用模型。角色首次加载后会生成透明缩略图，缓存在 `desktop-pet/previews/`；尚未使用的角色显示占位提示。

1.2 气泡参照 DaiMeow 头顶白色圆角样式，普通回复约 6 秒后用 0.3 秒淡出。随机动作默认 5–20 秒；DaiMeow 坐站 60–120 秒，70% 站／30% 坐，站姿21动作、坐姿17动作。特殊动作的道具轨迹与显隐已移植，普通角色保持通用逻辑。模型动作元数据按真实 File 识别，兼容导入后重命名的分组。

相同动作的手动 FORCE 重播先预加载，再处理 SDK 0.4.0 对 current/reserved 同组同索引的拒绝条件；预览必须收到 renderer 回执才显示成功。隐藏、停用、重载、切换和关闭会取消等待并清理叠加层。`runtime.animation` 为本次运行的轻量诊断，不写入聊天或观察历史。

首次无角色时安装 Hiyori 官方示例；已有角色不会被覆盖。更换角色时选择其完整导出文件夹内的 `.model3.json`，保持模型、贴图和动作的相对路径。导入仅接受本地模型资源，不执行模型包中的代码。

自动屏幕观察默认关闭。开启后默认每 30 秒检查，画面变化较小时跳过模型请求，180 秒无操作暂停。自动观察默认上限每小时 60 次、每天 200 次，可在页面修改。手动观察只防并发重复点击，不受这套自动次数限制；上游 API 的限额和费用仍适用。停止会取消本机等待和迟到回复，上游已经开始处理的请求是否计费由服务商决定。

截图仅在请求内存中处理，不写入历史文件；文字回复、场景、模型和 Token/估算费用保存在当前 QQ Agent 数据目录的 `desktop-pet/state.json`。截图发给所选模型 API，回复显示在本地桌面，不自动发送到 QQ。

角色动作取决于模型本身。示例 Hiyori 有 10 个动作，没有独立表情文件；站坐等专属姿态只有模型本身提供相应动作或表情时才可使用。
