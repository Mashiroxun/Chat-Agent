## 六、关键结论

1. **一超多强、长尾极长**：0.4.0 一个版本占 83.68%，官网下载页（version.json 指向 V0.4 Preview 安装包）是绝对主分发渠道；0.3.0 以 7.40% 居次席，属于还没升级的老用户。
2. **新版推广明显滞后**：GitHub 仓库最新正式版 0.4.8.9（2026-10-22 发布）全网只有 4 个实例在用（0.018%），整个 0.4.8.x 线合计也仅 6.03%——新版基本只在小圈子/免安装包玩家手里流通，官网主包仍停在 0.4.0。
3. **版本号混乱是常态**：43 个版本里混着 preview / fork / -wb / -jingyu / a / fixed 等自改后缀，甚至出现 9.9.9、4.2.0、2.0.0 这类明显乱填的版本号，另有 7 个实例上报"未知版本"。
4. **用户盘子涨得很快**：10-20 起连续三天日增 4,000 上下（10-22 单日 4,224），今天半日已新增 1,944；活跃度很高，60% 的实例今天仍有上报。
5. **留存储局**：次日留存 61.53%，四成新用户第二天不再打开；但老用户黏性极强——42% 的实例累计调用超 1,000 次，头部 1% 的实例贡献了 13.4% 的调用量。
6. **输入 Token 占 99%**：符合其"无状态会话 + 存档摘要"架构——每次都重放系统提示词与存档摘要，缓存命中与摘要压缩是成本大头。

## 七、与本机的对照

- 本机安装：`G:\QQagent`，版本 **0.4.8.9**（免安装"洛版"，基于 GitHub 仓库 2026-10-22 最新版打包），与全网 43 个版本中的 4 个实例同版本。
- 官网 version.json 当前最新版：**0.4.0**（V0.4 Preview Setup.exe）——即全网 83.68% 用户所用的版本，比本机旧约两个月迭代。
