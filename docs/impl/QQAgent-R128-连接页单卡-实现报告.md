# QQAgent R128 · 连接页改成「单卡」：一个表情 + 一句话 + 一个按钮

> 版本：0.4.9.1（运行目录 `G:\QQagent\resources\app`）
> 日期：2026-10-27
> 反馈：「这个界面对于那些人来说还是太复杂了」

---

## 一、R127 错在哪

R127 把 8 个区块折叠成 4 个，按钮从 10 个降到 1 个 —— 但那只是**减少了信息量**，
没有解决**信息本身**的问题：

- 还在讲"协议端""注入""OneBot""端点令牌"——这些词目标用户一个都不认识；
- 还在给"步骤条"——他得先理解"一共有几步、我在第几步"；
- 还在让他判断"该点哪个"——两枚按钮并排摆着，他不知道区别。

**正确做法是把状态机藏起来**，对外只暴露三样东西：一个表情、一句人话、一个按钮。

## 三、关键设计

### 3.1 把 13 个内部阶段翻译成 13 句人话

| 后端阶段 | 用户看到的 |
|---|---|
| `no-dir` | 📦 还缺一个「连接组件」 |
| `stopped` | 😴 机器人还没上线 |
| `booting` | ⏳ 正在启动… |
| `need-password` | 🔑 还差一个密码 |
| `locked` | ⏰ 试太多次，被暂时锁了 |
| `need-totp` | 🔐 需要动态验证码 |
| `consent` | 📄 需要你本人同意条款 |
| `must-change` | 🔑 需要先改一个密码 |
| `no-qq` | 💬 请先登录 QQ |
| `pick` | 👥 有两个以上的 QQ 在登录 |
| `can-inject` | 🔗 可以连接了 |
| `ready` / connected | ✅ 机器人已上线 |

术语全部消失：没有"协议端"（改叫"连接组件"）、没有"注入"（改叫"连接"）、
没有"OneBot"（不提）。

### 3.2 点一次，自己往下走

`connAutopilot()` 在前端循环：

```
拉一次接入状态
  ├─ stopped      → 启动组件 → 等 1.6s → 再来一轮
  ├─ booting      → 等 1.5s → 再来一轮
  ├─ can-inject   → 注入 → 等 0.9s → 再来一轮
  ├─ ready        → 停（成功）
  └─ 其余         → 停（必须用户本人：密码/同意/改密码/登录QQ/选号）
```

为什么不放后端一个长请求：每一步都要立刻改文案（"正在启动…"→"正在连接 QQ…"），
长请求期间页面只能干等。

### 3.3 唯一不能代劳的：下载

EULA 不允许替用户部署，所以 `no-component` 这一步只给「去下载」按钮（打开官方仓库），
下载解压后把路径填进输入框 —— **失焦即自动保存并继续**，不用再找"确定"。

### 3.4 高级设置一个功能没少

端点地址与令牌、组件进程与日志、随 QQ Agent 自动启动、应用日志、诊断详情、复制诊断信息，
全在默认合上的「高级设置」里。老用户展开就能用。

## 七、还留着的一个取舍

`pick`（多个 QQ 在线）仍然要让用户选 —— 这是**故意的**：自动挑一个的话，很可能挑中
用户的个人号，机器人会顶着那个号在群里说话。宁可多问一句。

## 八、补充：没装 SnowLuma 的人怎么办（R129）

单卡上线后暴露的下一个问题：**"还缺一个连接组件"这句话对没装的人来说等于没说**。
点「去下载」跳到一个全英文的 GitHub 页面，不知道该下哪个文件；下完要解压；
解压完还得知道该选哪一层目录。

### 8.1 改成三步引导

```
📦 还差一个软件要装
它叫「SnowLuma」，是个独立小软件，专门负责跟 QQ 打交道。我没法替你装，跟着下面三步走就行。

① 下载
   点开下载页，找名字里带 win-x64 的那个 zip（几十 MB）。
   [打开下载页]

② 解压
   右键那个 zip →「全部解压缩」。放桌面就行。

③ 告诉我它在哪
   选解压出来的那一层文件夹 —— 里面应该能看到 index.mjs 和 node.exe。
   [选择文件夹]  [帮我找]
```

截图：`conn-单卡-没装三步.png`。

### 8.2 新增「选择文件夹」

这是这一轮最关键的改动。让完全不懂的人照着
`C:\Users\xxx\Desktop\SnowLuma-v2.1.1-win-x64` 手动敲一遍 —— 反斜杠、版本号、
解压多一层目录，**任何一处错都表现为"填了没反应"**，而他根本不知道自己错在哪。

- 新增 IPC `app:pick-directory`（`electron/main.js`）+ preload 的 `pickDirectory()`；
- 安全口径与 `openProtocolConsole` 一致：只返回用户在**系统对话框里亲手选中**的路径，
  渲染进程传不进任何路径参数（`title` 只当文案，截断 80 字，不参与路径拼接）；
- 选完立刻落盘 → 自动往下走（启动 → 等端口 → 登录 → 注入）；
- 选错层（那层没有 `index.mjs`）会在启动时报"这个目录里没有 index.mjs"，够他判断。

### 8.3 网页版回退

浏览器里没有这个桥，`connAutoBody` 会检测 `window.qqaDesktop?.pickDirectory`
自动回退成"输入框 + 帮我找"。截图：`conn-单卡-没装-网页版.png`。

### 8.4 下载地址

「打开下载页」指向 `github.com/SnowLuma/SnowLuma/releases`（不是仓库首页）——
首页还要再点一次 Releases，多一步就是多一次流失。

> ⚠️ 仍然**没有**做自动下载/自动解压：EULA 5.4 条明确把"通过自动化脚本部署"列为
> 需书面授权的行为。这条线不碰，所以第 1、2 步必须用户自己动手 ——
> 能做的只是把它说得足够清楚、把第 3 步简化成两次点击。

## 九、打磨：单卡不能只是"空"，要"有分量"（R130）

单卡上线后的反馈是"多少有点太简陋了"。判断是对的 —— **简单不等于空洞**：
一张 620px 的大卡只放三行字，看起来像占位符。

### 9.1 emoji 换成线性 SVG

Windows 的彩色 emoji 在深色底上是个实心色块，边缘发虚、大小随字体变，
和这套细线条 UI 完全不搭（截图里那个绿色方块就是 ✅）。

现在统一成 `56px 圆底 + 26px stroke 图标`，按处境给不同图形：
对勾 / 下载 / 电源 / 钥匙 / 对话气泡 / 多人 / 文档 / 链接 / 警告三角 / 放大镜，
`starting` 那个还会转圈。颜色跟随 ok / warn / off 三档。

### 9.2 已连接时换成头像

```
              ╭──────╮
              │  小  │     ← 昵称首字 + 按 QQ 号取的固定渐变 + 呼吸的在线绿点
              ╰──────╯
            机器人已上线
      小鲸鱼 · 1781636009  [已在线 2 小时 14 分]
   ──────────────────────────────────────
   收消息 ws://127.0.0.1:3001   发消息 http://127.0.0.1:3000
```

- 头像颜色按 QQ 号哈希取固定渐变 —— 同一个号永远同一个颜色，换号能一眼看出；
- 在线绿点带 2.6s 的呼吸光晕（CSS `@keyframes autoPulse`）；
- 补 `昵称 · QQ号 · 在线时长` 一行，把"谁在线、在线多久"说清楚；
- 收/发两个端点压成两列小字放在虚线下面 —— 是"真的连着"的证据，但不占注意力。

### 9.3 后端补一个字段

`onebot.connectedAt`（本次上线时刻）：

- 只在"未连 → 已连"时记一次，**断线重连不重置** —— 否则时长会永远显示几秒；
- 断开时置 null；
- `/api/status` 里透出，前端 `connUptime()` 算人话（`刚刚上线` / `已在线 23 分钟` /
  `已在线 2 小时 14 分` / `已在线 3 天 5 小时`）；
- 时长跟着 15 秒的轮询刷新，不会停在页面刚打开时那个数。

### 9.4 视觉细节

- 已连接卡片加极淡的绿色光晕（`0 10px 34px green/9%`），不再是"纯色块 + 三行字"；
- 昵称 15px、QQ 号 11.5px 等宽 + 60% 透明、时长做成绿色胶囊 —— 三层信息一眼分层。
